# 🚀 Quick Start Guide - IGI Gaming

## 5-Minute Setup for IGI

### Step 1: Run Application (1 min)
```bash
python main.py
```

### Step 2: Calibrate (1 min)
1. Go to **Calibration** tab
2. Point index finger to **TOP-LEFT** corner where you want to control
3. **Pinch** (thumb + index together)
4. Point to **BOTTOM-RIGHT** corner
5. **Pinch** again
6. Done! ✅

### Step 3: Enable Control (10 sec)
1. Go back to **Dashboard**
2. Toggle **Mouse Control** switch ON
3. Test by pointing finger - cursor should move

### Step 4: Launch IGI (30 sec)
- Start Project IGI / IGI 2
- Load any mission

### Step 5: Play! 🎮

---

## 🖐️ Quick Gesture Reference

| What to do | Result |
|------------|--------|
| 👆 Point index finger | Aim weapon |
| 🤏 Pinch thumb+index | Shoot (hold = auto) |
| 🤌 Pinch thumb+middle | Zoom/Right-click |
| 🤟 3 fingers up | Sniper steady aim |
| 🖖 4 fingers up | Reload |
| ✊ Make fist | Pause |
| 🖐️ Open palm | Resume |

---

## ⚠️ Important Tips

1. **Good Lighting = Success** (Most important!)
2. **F10 = Emergency Stop** (if cursor goes crazy)
3. **Keep hand 1-2 feet from camera**
4. **Rest elbow on desk** for steady aim
5. **Practice 5 minutes** before playing

## 🐛 Quick Fixes

**Cursor too fast?** → Settings → Reduce Sensitivity
**Cursor too slow?** → Settings → Increase Sensitivity
**Lag?** → Close other apps, check lighting
**Hand not detected?** → Improve lighting, wear solid color shirt
